# ULTRON AI

### A Holographic AI Assistant Experience

**ULTRON AI** is an AI assistant project created by **Eswar Kutala**. It brings together a futuristic holographic interface, an interactive 3D orb, an expandable assistant chat panel, and voice- and gesture-oriented controls.

The project is presented as a live web application. Open the deployed website to experience the interface—there is no local setup or command-line usage required to access the live version.

## The Experience

ULTRON AI explores a more visual and interactive way to interact with an AI assistant.

### Holographic Orb
The main interface features an animated orange-and-gold holographic orb, surrounded by illuminated rings, energy-like lines, particles, and a glowing spherical field.

### Expandable Assistant Chatbox
A circular control near the bottom of the page opens a compact assistant chatbox. The panel displays the ULTRON AI identity, an online indicator, a welcome message, a text input, and a Send control.

### Voice Interface
The chat panel includes voice-related controls, including a voice toggle and microphone button.

### Gesture Interface
A dedicated gesture-control area is presented alongside the holographic experience.

### Orb Interaction
On-screen controls provide options for interacting with the orb, including spin, zoom, and reset controls.

*The availability and behavior of individual assistant, voice, and gesture capabilities depend on the current live implementation and service configuration.*

## Technology

The project uses the following technologies across its frontend, visual interface, computer-vision functionality, and backend:

| Technology | Role |
|---|---|
| Next.js | Frontend application framework |
| React | User interface |
| TypeScript | Application development |
| Three.js | 3D orb and visual effects |
| MediaPipe Tasks Vision | Hand-tracking and computer-vision functionality |
| Node.js | Backend runtime |
| Express.js | Backend API framework |
| GitHub Pages | Live frontend hosting |
| Render | Backend hosting |

| Component | Deployment |
|---|---|
| Frontend | GitHub Pages |

- **Live application:** [Open ULTRON AI](https://eswaraitechnology.github.io/Ultron-AI-By-Eswar-/)
